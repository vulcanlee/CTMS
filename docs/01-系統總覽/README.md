# 01-系統總覽 — 這系統在做什麼

本目錄回答「**這是什麼系統、為誰做、整體怎麼運作**」，是所有新進人員（含 AI 助手）的第一站。不談實作細節，細節一律連到後面的分類。

| 文件 | 說明 |
| --- | --- |
| [接手指南](接手指南.md) | **接手第一份該讀的**：系統在幹嘛、程式碼放哪、看哪裡。⚠️ 第 6 節「容易踩到的地雷」是全 repo 最省時間的一節——臨床資料**不在資料表裡**而是序列化在 `Patient.JsonData`，直接查資料庫看不到；`/Export` 頁是空殼，真正的匯出按鈕在個案清單 |
| [系統總覽](系統總覽.md) | 領域、目的、五種角色、資料生命週期鳥瞰。⭐ 醫院清單**不在本文件**，唯一出處是 `HospitalRegistry.All`（見 [新增醫院](../07-擴充指南/新增醫院.md)） |
| [畫面導覽地圖](畫面導覽地圖.md) | 全系統路由的 mermaid 導覽圖、六個切換鈕的權限閘門、每個畫面「為什麼需要、誰會用」。🔴 「臨床資料」按鈕與目的頁檢查的是**兩個不同的權限** |

## 兩份文件的分工

- **接手指南**＝白話、快、給人看，目標是三十分鐘內能動手。
- **系統總覽**＝完整、給人與 AI 看，目標是理解領域與角色。

要動手改程式前，兩份都不夠——請先看 [開發慣例與限制速查](../02-架構/開發慣例與限制速查.md)。
