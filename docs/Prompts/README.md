# Prompts — 提示詞原稿

本目錄收納開發過程中**實際用過的需求提示詞原稿**。

⚠️ **原稿保留，不要整理。** 整理過的提示詞會失去它唯一的價值——「當初實際是這樣問的」。這裡不是規範文件，不需要標頭區塊，也不需要與現況同步。

| 文件 | 說明 |
| --- | --- |
| [prompt history](prompt%20history.md) | 歷次需求提示詞的原稿累積 |
| [Sample](Sample.md) | 提新需求時的提示詞範本：描述需求、限制與條件，並要求反覆提問確認 |

> 系統執行期使用的提示詞（例如操作歷程的 AI 差異摘要）在程式或資料庫裡，不在本目錄。
