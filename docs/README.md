# CTMS 文件總導覽

本目錄是 CTMS（婦科癌症臨床試驗管理平臺）的系統文件，供**人類開發者、AI 助手與系統使用者**理解這套系統怎麼運作、怎麼改、怎麼用。

> 編碼規範：本目錄所有 `.md` 採 UTF-8 **含 BOM**、繁體中文。提交前請在本機執行 [scripts/Test-Docs.ps1](../scripts/Test-Docs.ps1)（六項檢查：編碼、連結與錨點、索引完整性、標頭、易腐數字、KM 章節）。⚠️ 本專案**沒有 CI**，這支腳本不會自動擋下提交——是靠人記得跑。規範全文見 [文件維護規範](06-部署與維護/文件維護規範.md)。
