# 03-資料模型 — 資料長什麼樣子

本目錄說明 CTMS 的資料如何被儲存與組織。改欄位、加 Migration、寫匯出之前都要先看這裡。

| 文件 | 說明 |
| --- | --- |
| [領域資料模型](領域資料模型.md) | EF 實體與 `PatientData` / `JsonData` 結構。🔴 **大部分臨床資料不是資料表**，而是整包序列化進 `Patient.JsonData`——用 SQL 查不到抽血、化療、副作用等明細，必須反序列化才看得懂 |
| [VisitCode-資料結構與關聯](VisitCode-資料結構與關聯.md) | 回診次別的四個欄位、標題組成規則、與各類資料的一對多關聯。🔴 `CompareTo` 不看 `Id` 但畫面關聯用 `Id`；🔴 Visit Code 以**複本**散在各類資料中，改一處不會同步 |
| [問卷與抽血資料的建立與維護](問卷與抽血資料的建立與維護.md) | 兩類資料如何從 `Data/` 的 JSON 範本產生。🔴 **範本改動不回溯既有病人**，不同時期收案的資料結構會不一致 |

> 資料庫工具、Migration 操作與歷史紀錄在 [資料庫與 EF Core](../06-部署與維護/資料庫與EFCore.md)，不在本目錄。
