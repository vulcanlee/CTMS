# 09-變更紀錄 — 每次有意義異動的紀錄

本目錄一次有意義的異動一份，檔名為 `YYYY-MM-DD-主題.md`。

**這裡要寫的是「為什麼」，不是「改了什麼」。** 只列改動項目的紀錄等同 `git log`，沒有存在必要；真正有價值的是**根因**那一節——說明為什麼看起來對的修法其實無效。

| 文件 | 說明 |
| --- | --- |
| [2026-08-10 建立文件防腐機制](2026-08-10-建立文件防腐機制.md) | 三層索引、文件標頭、易腐數字唯一出處與 `scripts/Test-Docs.ps1` 守門腳本的建立紀錄 |

> ⚠️ 新增一份 changelog 要**同時**更新兩處索引：本檔與 [docs/README.md](../README.md)。只漏一處不會有任何錯誤訊息——這是最容易發生的漂移，`scripts/Test-Docs.ps1` 的索引完整性檢查就是為了擋它。
