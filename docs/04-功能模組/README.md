# 04-功能模組 — 各畫面的商業邏輯

本目錄一個「功能模組」一份，說明**開發者視角**的資料來源、計算方式與畫面商業邏輯（欄位驗證、條件顯示）。要找使用者視角的欄位與按鈕說明，看 [KM 使用者知識庫](../KM/)。

> 幾乎所有臨床資料都掛在某一次回診（**Visit Code**）之下，同一位受試者會有多筆。看任何一份模組文件前先理解這個概念（見 [資料流與分層](../02-架構/資料流與分層.md)）。

## 個案與總覽

| 文件 | 說明 |
| --- | --- |
| [個案管理](個案管理.md) | `/Browser` 受測者清單：搜尋、篩選、新增、狀態切換。⚠️ 三種匯出永遠針對**全部受試者**，不受畫面上的篩選影響 |
| [儀表板](儀表板.md) | `/Dashboard` 各卡片與圖表的資料來源與計算方式，含「依醫院分組」邏輯與新增醫院時必須一起調整的程式點 |
| [收案進度統計](收案進度統計.md) | `/EnrollmentProgress` 醫院 × 癌別 × 期別 × 組別交叉統計表，供研究簡報截圖用 |

| 文件 | 說明 |
