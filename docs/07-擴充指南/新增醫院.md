# 擴充指南：新增醫院

本指南說明 CTMS 系統中新增一家醫院的完整做法。自 2026/07 起（版本 1.1.222），醫院定義已集中至 **`HospitalRegistry`**（單一醫院清單），原本散落約 18 處的 `switch` / 連續 `if` / 固定清單皆已改為讀取此清單，新增醫院從「跨多檔的 18 點修改」簡化為「**清單加一筆 + 備妥資料檔**」。

## 1. 背景

系統目前支援六家合作醫院（五個 prefix 擁有者 + 一個共用 prefix 的分院）：

| 代碼（Prefix） | Sheet 短名 | 院別全名 | 說明 |
| --- | --- | --- | --- |
| `NCKUH` | 成大 | 成大醫院 | |
| `CHIMEIH` | 奇美 | 奇美醫院 | |
| `KGH` | 郭綜合 | 郭綜合醫院 | |
| `CHIMEIH`（沿用奇美） | —（歸奇美） | 柳營奇美醫院 | **共用 prefix 分院**：編號、隨機表、抽血檔、儀表板皆比照奇美，僅 `Patient.醫院` 顯示不同 |
| `KSVGH` | 高榮 | 高雄榮民總醫院 | 2026/07 新增 |
| `CYCGMH` | 嘉長 | 嘉義長庚紀念醫院 | 2026/07 新增 |

## 2. 醫院清單的定義來源（單一來源）

所有醫院的「來源真相」集中在 [HospitalRegistry.cs](../../src/CTMS/CTMS.Share/Helpers/HospitalRegistry.cs)（位於最底層的 CTMS.Share，全解決方案皆可引用）。每筆 `HospitalDefinition` 包含：

| 欄位 | 用途 |
| --- | --- |
| `Prefix` | SubjectNo 前綴（院區群組鍵），如 `KSVGH` |
| `DisplayName` | 院別全名 = 下拉字串 = `Patient.醫院` 存放值 |
| `ShortName` | 短名（儀表板長條、隨機表分頁、RandomPage Tab 標題） |
| `SheetEarly` / `SheetAdvance` | RandomList.xlsx 分頁名 |
| `BloodHematologyFile` / `BloodBiochemistryFile` | 抽血檢驗血液 / 生化 JSON 檔名 |
| `CounterKey` | `SubjectNoGenerator.json` 流水號鍵名（如 `KSVGH高榮`） |
| `IsPrefixOwner` | `false` = 共用 prefix 的分院（如柳營奇美），只參與院別下拉與院別→prefix 對應 |

查詢方法：`PrefixOwners`（迭代用，排除共用 prefix 分院）、`GetByDisplayName(院別)`、`GetOwnerByPrefix(prefix)`、`GetOwnerBySubjectNo(subjectNo)`、`NormalizeToOwnerShortName(Patient.醫院)`（儀表板歸戶，**DisplayName 精確比對優先**）。

字串常數仍定義於 [MagicObjectHelper.cs](../../src/CTMS/CTMS.Share/Helpers/MagicObjectHelper.cs)（prefix、短名、Sheet 名、抽血檔名），registry 引用這些常數。

以下皆已改為讀取 registry，**新增醫院時不需再修改**：

- 受試者編號產生：[SubjectNoGeneratorService.cs](../../src/CTMS/CTMS.Business/Services/ClinicalInformation/SubjectNoGeneratorService.cs)（`GetOwnerByPrefix` + `Counters[CounterKey]`）
- 流水號模型：[SubjectNoGeneratorModel.cs](../../src/CTMS/CTMS.DataModel/Models/ClinicalInformation/SubjectNoGeneratorModel.cs)（`Dictionary<string,int>`，缺鍵自動補 0）
- 院別→prefix 對應：[PatientService.cs](../../src/CTMS/CTMS/Services/PatientService.cs)（`GetByDisplayName`）
- SubjectNo 反查醫院 / 抽血檔名：[SubjectNoHelper.cs](../../src/CTMS/CTMS.Business/Helpers/SubjectNoHelper.cs)
- 隨機分組 Hospital 判定：[RandomParameterMode.cs](../../src/CTMS/CTMS.DataModel/Models/ClinicalInformation/RandomParameterMode.cs)
- 隨機表讀取：[RandomListService.cs](../../src/CTMS/CTMS.ExcelUtility/Services/RandomListService.cs)（`foreach PrefixOwners` + 自癒補讀，見 §6）
- 儀表板：[DashboardService.cs](../../src/CTMS/CTMS.Business/Services/DashboardService.cs)（`HospitalNames`、`HospitalStats`、`GetHospitalName`）
- 院別下拉：[DropDownListDataService.cs](../../src/CTMS/CTMS.Business/Services/ClinicalInformation/DropDownListDataService.cs)（`foreach All`）
- 單列 CSV 匯出院名：[PatientSingleRowCsvExportService.cs](../../src/CTMS/CTMS.Business/Services/ClinicalInformation/PatientSingleRowCsvExportService.cs)
- 隨機表維護分頁：[RandomPage.razor](../../src/CTMS/CTMS/Components/Pages/AdminTools/RandomPage.razor)（每家自動產生 EC/OC × Early/Advance 四分頁）
- 流水號後台維護：[LastSubjectNoView.razor](../../src/CTMS/CTMS/Components/Views/AdminTools/LastSubjectNoView.razor)（依 `PrefixOwners` 動態產生欄位）

## 3. 新增一家醫院的修改清單

> 假設新增「範例醫院」，代碼 `XXX`、短名「範例」。

| # | 位置 | 要改什麼 |
| --- | --- | --- |
| 1 | [MagicObjectHelper.cs](../../src/CTMS/CTMS.Share/Helpers/MagicObjectHelper.cs) | 新增常數：`prefix範例醫院="XXX"`、`PrefixSheetName範例醫院="範例"`、`Sheet範例Early/Advance`、（如需獨立抽血檔）`範例抽血檢驗血液File/生化File` |
| 2 | [HospitalRegistry.cs](../../src/CTMS/CTMS.Share/Helpers/HospitalRegistry.cs) | 在 `All` 清單加一筆 `HospitalDefinition`（引用上述常數，`CounterKey` 如 `XXX範例`） |
| 3 | [Data/RandomList.xlsx](../../src/CTMS/CTMS/Data/RandomList.xlsx) | 新增「範例Early」「範例Advance」兩分頁並填入該院隨機碼（欄位 A=Id、B=BlockId、C=BlockSize、D=Treatment、E=SubjectNo 留空；資料自第 2 列起，勿超過 2000 列） |
| 4 | `Data/抽血檢驗血液N.json` / `生化N.json` | 若抽血項目與既有醫院不同，新增該院專屬檔（檔名與 #1 常數一致）；相同則直接沿用既有檔名 |
| 5 | [dashboard.js:142-144](../../src/CTMS/CTMS/wwwroot/js/dashboard.js) | （選配）fallback 陣列補上短名與預設 0，正常路徑由 ViewModel 驅動 |

`Data/SubjectNoGenerator.json` **不需手動改**：`ReadAsync` 會對 registry 中的每個 prefix 擁有者自動補 0（起始流水號非 0 時才需手動設定或由後台 `/Random` 的「最後自動編號」調整）。

### 3.1 新增「共用 prefix 的分院」（如柳營奇美）

只需在 registry 加一筆：`Prefix` 填擁有者的 prefix、`DisplayName` 填分院全名、`IsPrefixOwner = false`，其餘欄位免填。編號、隨機表、抽血檔、儀表板自動比照 prefix 擁有者；唯 `Patient.醫院` 存分院全名供顯示與篩選。

## 4. 操作步驟

1. **常數 + registry**（§3 #1、#2）→ `dotnet build` 確認編譯。
2. **資料檔**（§3 #3、#4）→ 分頁名務必與常數完全一致；分頁名對不上（或尚未備妥）時，`RandomListService` 會**略過該分頁並記一筆 `Trace` 警告**（不再擲例外中斷啟動），但該院隨機表在補上正確分頁前為空。
3. 啟動系統 → `RandomListRuntime.json` 既存時會**自癒補讀**新院分頁（見 §6），不需刪快取。
4. 依 §5 驗證清單逐項確認。
5. 依專案規範更新 `appsettings.json` 版本號（Patch +1）並更新相關文件。

## 5. 驗證檢查清單

- [ ] 新增病人對話框院別下拉出現「範例醫院」。
- [ ] 選「範例醫院」收案後，受試者編號為 `XXX0001` 並逐次遞增；`SubjectNoGenerator.json` 的 `XXX範例` 計數同步增加。
- [ ] 隨機分組能從新院的 Early/Advance × EC/OC 分頁取得隨機碼並回填 Treatment（AI/Dr）。
- [ ] 抽血檢驗能依新院抓到正確的 `抽血檢驗血液N.json` / `抽血檢驗生化N.json`。
- [ ] 進入 `/Dashboard`：合作醫院卡片數 +1、副標含「範例」；醫院統計長條圖出現「範例」一欄且病例數正確。
- [ ] 瀏覽頁院別篩選可勾選「範例醫院」並正確過濾。
- [ ] CSV 單列匯出時院名欄位正確顯示「範例醫院」。
- [ ] `/Random` 後台出現新院四個分頁；「最後自動編號」出現新院欄位。
- [ ] **既有醫院回歸**：編號接續、隨機分配保留、儀表板數字不變。

## 6. 注意事項與風險

- **儀表板歸戶採 DisplayName 精確比對**：`GetHospitalName` → `NormalizeToOwnerShortName` 先以 `Patient.醫院` 與 `DisplayName` 精確比對（「高雄榮民總醫院」不含短名「高榮」，靠 `Contains(短名)` 必定漏算），`Contains(短名)` 僅為既有資料的容錯 fallback。registry 的 `DisplayName` 必須與院別下拉存入 `Patient.醫院` 的字串一致（由 `Get院別()` 讀同一清單保證）。
- **`RandomListRuntime.json` 不是單純快取**：它保存已落地的隨機分配結果（已用亂數列的 `SubjectNo` 回填、換組時標記 `**`）。**不可在生產環境刪檔重建**（會清空既有分配）。`RandomListService.InitialAsync` 具**自癒補讀**：快取存在但缺少 registry 中某院的資料時，只從 xlsx 補讀該院分頁附加存檔，既有分配不受影響——新增醫院後的升版零手動步驟。開發環境要「全新重建」才刪除該檔。
- **編號連續性**：`SubjectNoGenerator.json` 為扁平 JSON（鍵 = `CounterKey`）；`ReadAsync` 以 Dictionary 直讀並對缺鍵補 0，不再有「模型屬性與鍵名對不上而重號」的風險。既有計數鍵名不可改。
- **既有資料**：既有醫院的 `Patient.醫院` 值與 `SubjectNo` 前綴已落地，**不可更動既有常數字串與 `DisplayName`**，只做「新增」不做「改名」。
- **目標收案人數**：儀表板完成率分母 `TargetCases` 固定為 294（[DashboardViewModel.cs:50](../../src/CTMS/CTMS.DataModel/Models/Dashboard/DashboardViewModel.cs)），新增醫院若改變總目標人數須一併調整。
- **prefix 不保證與醫院一對一**：允許多個院區共用 SubjectNo prefix（柳營奇美沿用 `CHIMEIH`）。凡以 `SubjectNo` 反查醫院的點（`SubjectNoHelper`、`RandomParameterMode.Parse`、`PatientSingleRowCsvExportService.ResolveHospital`）都是「**院區群組層級**」——共用 prefix 的分院會被視為 prefix 擁有者（例如柳營奇美的 CSV 匯出院名顯示「奇美醫院」，為現階段預期行為）。需要區分實際院區時**必須讀 `Patient.醫院`，不可用 prefix 反查**。詳見 [新增三家醫院-實施做法 §0.1](新增三家醫院-實施做法.md)。
