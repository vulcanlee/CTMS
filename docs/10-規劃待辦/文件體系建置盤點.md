## 三、⚠️ 推測項清單

本次建置**沒有**在任何文件中寫入未經查證的內容。以下是有意識地標記為「不確定」而寫進文件的項目，供日後查核：

| 項目 | 寫在哪 | 為什麼不確定 |
| --- | --- | --- |
| 正式環境是否提供 `BackendSystemAssistant:GodPasswordSlat` / `GodrPasswordHash` | [認證授權與權限機制](../11-資安/認證授權與權限機制.md) 第四節 | repo 內兩個 `appsettings*.json` 都沒有這一段；環境變數或 user-secrets 無法從 repo 判斷 |
| 權限變更後已登入使用者的 `RoleJson` 何時刷新 | 同上文件第六節 | 只查到登入時複製一次，未追出刷新時機 |
| 登入失敗次數限制與帳號鎖定是否存在 | 同上文件第六節 | 未查到相關程式 |
| 分類 README 中對各文件的「最關鍵的坑」 | 各分類 `README.md` | 取自文件本身的敘述，未逐項回頭核對程式碼 |
